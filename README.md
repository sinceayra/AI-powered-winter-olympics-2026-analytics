# AI-Assisted Winter Olympics 2026 Analytics

## Overview

This project presents an end-to-end exploratory data analysis (EDA) of the **2026 Winter Olympics** dataset using **R** and an interactive **Tableau** dashboard. The workflow includes data cleaning in **Microsoft Excel**, statistical analysis in **R**, and dashboard development in **Tableau**. Modern AI tools were integrated throughout the development process to improve productivity and streamline the analytics workflow.

---

## Project Objectives

- Perform exploratory data analysis using R.
- Analyse athlete demographics, country performance, and medal trends.
- Identify relationships between athlete characteristics and performance.
- Develop an interactive Tableau dashboard for data storytelling.
- Demonstrate an AI-assisted analytics workflow.

# Key Findings

## Country Analysis

- USA and Switzerland sent the largest delegations (**23 athletes each**).
- Countries with greater Olympic experience generally performed better.
- Smaller delegations achieved strong medal-to-athlete ratios.
- Medal distribution varied considerably across participating nations.

## Athlete Demographics

- Athlete ages ranged from **18–41 years**, with an average age of **28.6 years**.
- Most athletes were between **24–30 years**.
- Medalists had a slightly higher median age than non-medalists.
- The **28–32** age group produced the most Gold medalists.
- Gender representation was nearly balanced (**127 Female, 123 Male**).

## Sport & Event Analysis

- Ice Hockey had the highest participation (**25 athletes**).
- Sports with multiple events produced the most medalists.
- Team and individual events displayed different medal patterns.
- Only two Olympic record holders were identified.

## Physical Attributes

- Male athletes were generally taller and heavier.
- Height and weight showed a strong positive relationship.
- Physical profiles differed across sports.
- Medalists and non-medalists displayed similar physical characteristics.
- BMI varied considerably between sports.

## Career & Performance

- Identified the Top 10 athletes by career medals.
- Greater Olympic experience was associated with more career medals.
- Olympic record holders were profiled.
- Figure Skating scores showed clear separation between medal categories.
